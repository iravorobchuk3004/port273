# PORT°273

Landing page for PORT-273, an industrial cultural hub in Kyiv: four spaces for rent, upcoming events and a booking request form. Concept project by Iryna Vorobchuk.

Static HTML/CSS/JS, no build step. Open `index.html` or serve the folder:

```bash
python3 -m http.server 8273
```

Fonts: Syne for display, e-Ukraine for body text when installed (Montserrat is the web fallback).
